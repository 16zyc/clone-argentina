# CLONE Centro de Operaciones IA - 产品原型设计规格

## 1. 目标与边界

为阿根廷 B2B 批发商户制作一个可点击、可路演的西班牙语高保真网页原型。产品不定位为普通 BI 看板，而是“可执行、可审批、可追溯的 AI 业务团队”。路演主线是 AI 自动运营的一天：夜间执行、早间汇报、白天决策、当日复盘。

本轮为前端演示原型，使用可信的模拟数据，不接入真实 DEONCE、Mercado Libre、WhatsApp、1688、仓储或 AFIP API。

CLONE 是 DEONCE 的 AI 运营层，不取代原有交易平台。DEONCE 提供商户、客户、订单、SKU、价格和库存等业务对象；CLONE 与外部渠道、供应链和合规数据组合决策，再将结果和审计记录回写 DEONCE。

## 2. 设计原则

- 业务先于技术：首屏先呈现收益、风险和待决策事项，技术架构作为可下钻的依据。
- AI 不黑箱：所有关键任务均呈现 `Detectar → Analizar → Recomendar → Aprobar → Ejecutar → Auditar`。
- 人机共管：低风险任务自动执行，价格、采购、税务等高风险动作必须人工审批。
- 本地化：全界面使用西班牙语，金额为 ARS/USD，语境面向阿根廷批发业务。
- 比赛可演示：每个关键页面在 30-60 秒内能讲清楚一个产品价值点。

## 3. 信息架构

### 3.1 主导航

1. `Centro de mando` - 今日总览与时间线
2. `Operaciones` - 10 大运营环节与任务状态
3. `Equipo IA` - 专属 Agent 团队及协作路径
4. `Aprobaciones` - 高风险动作的人工审批中心
5. `Informes` - 日报、周报与审计记录

`Operaciones` 固定展示十项：订单与绩效、Listing 状态、竞品监控、评论与 Feedback、库存与货件物流、多语内容、老品优化、数据与退货分析、新品开发、站外流量。`TERMO-750` 归属第五项“库存与货件物流”。每项显示能力说明、当日信号数和状态；库存、竞品、评论三项可下钻。

### 3.2 主页结构

- 顶栏：当前商户、数据同步状态、通知、演示账户。
- 欢迎区：一句话概括夜间完成工作与今日最优先决策。
- KPI 区：今日销售额、AI 任务数、节省工时、预计利润影响。
- 时间线：按 `Noche / Mañana / Tarde` 分组展示任务。
- 决策卡：库存紧急补货作为主演示案例，展示证据、AI 建议、预期影响和审批按钮。
- Agent 协作区：展示监控、库存、供应链、合规 Agent 对同一决策的分工。

### 3.3 其他主视图

- `Operaciones`：10 张能力卡，默认显示全部，可切换“全部/有告警/自动”筛选。
- `Equipo IA`：左侧是调度器与 Agent 协作图，右侧是当日活动。“Forjar nuevo agente”模拟三步配置：业务目标、可用数据、审批边界；完成后新增演示 Agent 及审计记录。
- `Aprobaciones`：默认显示两项待审批和一项待复核，每项可查证据并触发模拟执行。
- `Informes`：三个报告入口与审计表。原型仅“预览导出”，成功反馈须显示文件名、格式和字段清单。

## 4. 演示场景

### 4.1 晨报与异常发现

AI 夜间已完成 128 项任务，发现三项需要关注的事件：重点 SKU 库存低于 9 天、Mercado Libre 竞品降价 6.8%、一条 2 星评论指向包装损坏。点击事件可查看数据证据和 Agent 建议。

### 4.2 库存补货决策

库存 Agent 根据过去 30 天销速、安全库存和交期计算缺口；供应链 Agent 比较两家供应商；合规 Agent 计算 HS 编码、关税与 AFIP 风险；调度 Agent 合成建议。用户可批准、调整数量或拒绝。批准后状态切换为已执行，并产生审计记录。

状态机为 `Pendiente → Aprobado → Programado → Ejecutando → Ejecutado`，原型使用 300-600ms 加速过渡。失败进入 `Fallido`，可重试或取消。调整数量产生新版本并回到 `Pendiente`；拒绝进入 `Rechazado` 并记录原因。审计字段包含事件 ID、时间、操作人、Agent、证据来源、前后值、状态和结果。

### 4.3 竞品响应

竞品降价事件下钻后展示历史价格、排名与销量趋势。AI 不建议直接跟价，而是建议为老客户创建 48 小时阶梯优惠。用户可预览影响，再进入审批。

审批后模拟在 DEONCE CRM 创建 324 人客户分组和 48 小时优惠规则，最终生成“已执行”审计记录。

### 4.4 客户反馈处理

评论事件展示西语原文、情绪、SKU、历史同类问题与根因分类。客服 Agent 生成回复草稿，品质 Agent 将问题加入批次追踪。

评论场景以“草稿可编辑 + 模拟发送 + 批次追踪已创建”为终点，不发送真实消息。

### 4.5 固定演示数据

- `TERMO-750`：库存 412 件，日均 47.8 件，覆盖 `412 / 47.8 = 8.6` 天；总交期 24 天，建议量 1,800 件。
- 供应商单价 USD 8.20，投资额 `1,800 × 8.20 = USD 14,760`；预计毛利率 36.2%，避免 16 天断货，保护销售额 ARS 18.4M。
- 竞品价格由 ARS 42,900 降至 ARS 39,990，约 6.8%；公开跟价将损失月毛利 ARS 2.1M。
- 评论 SKU `ORG-4N`，2 星，关联批次 `L-0826`，历史同类问题 7 条。

## 5. 交互与状态

- 主导航可切换五个主视图，当前项保持明确高亮。
- 时间线任务可展开侧边详情面板。
- 库存决策支持批准、调整与拒绝，并以 toast 和状态标签反馈。
- AI 对话入口提供三个预设问题，返回与当前业务数据相关的模拟答复。
- 报告支持预览导出，记录每次决策的数据来源、Agent、时间和人工审批人。
- 屏幕宽度小于 900px 时收起侧栏，主卡片改为单列。
- 顶栏提供 `Reiniciar demo`，将审批、任务、审计和新建 Agent 恢复为初始状态。

## 6. 视觉系统

- 风格：深色企业级 AI 指挥中心，不使用夸张的科幻装饰。
- 主色：深靛蓝黑背景，青绿色表示 AI 执行与收益，琥珀色表示待决策，红色表示高风险。
- 字体：无衬线字体，数字使用等宽数字特性。
- 图标：统一使用线性 SVG，不用 emoji 作为功能图标。
- 动效：150-300ms，仅用于视图切换、侧板进入、状态更新和数据提示。

## 7. 可访问性与容错

- 主要文字对比度达到 WCAG AA，关键状态不仅靠颜色表达。
- 所有可交互元素有明确的 hover、focus 和 pressed 状态，可用键盘操作。
- 对话、审批和导出操作均有加载、成功或失败反馈。
- 高风险操作不在原型中真实对外发送或下单。
- 顶栏同步按钮长按 800ms 或按住 Shift 点击时触发模拟失败，显示失败来源 `Mercado Libre` 与 `Reintentar`；点击重试后按钮恢复 `Sincronizado`。
- 正文对比度至少 4.5:1，大字至少 3:1，触控目标最小 44×44px。打开侧板或 Agent 配置后焦点进入容器，Tab/Shift+Tab 循环限制在容器内，Escape 关闭后焦点返回触发元素。SVG 协作图附带不可见文本摘要或 `aria-label`；toast 使用 `aria-live=polite`，`prefers-reduced-motion` 下取消位移和长动画。

## 8. 技术实现

使用无构建依赖的 HTML/CSS/JavaScript 单页原型，便于本地直接打开和比赛现场演示。模块包括视图路由、模拟数据、状态管理、图表 SVG、对话与审批交互。所有数据均在前端模拟，页面明示 `Entorno de demostración` 标记。

区域设定为 `es-AR`，时区为 `America/Argentina/Buenos_Aires`；ARS 使用当地千位点和小数逗号，USD 明确标记。

### 8.1 四分钟路演路径

1. 首页（40 秒）：讲 128 项夜间任务和四个 KPI。
2. 补货（70 秒）：点击 `TERMO-750`，讲四 Agent 证据链并审批。
3. AI 团队（35 秒）：展示协作图并演示 `Forjar nuevo agente`。
4. 竞品（45 秒）：展示不盲目跟价的利润保护决策。
5. 审计（30 秒）：进入 `Informes` 展示人、Agent、证据和结果。
6. 回首页（20 秒）：以“一支懂你业务的 AI 团队”收尾。

## 9. 验收标准

- 全界面主要用户文案为西班牙语。
- 五个主视图均可访问；`Operaciones` 正好显示 10 张卡，三个事件可下钻。
- 批准补货后，待审批计数减一，任务显示状态过渡，审计页新增操作人、时间、证据、前后值和结果。
- `Forjar nuevo agente` 可完成一次三步配置，返回后可见新 Agent。
- 在 1440×900 和 390×844 视口下无水平溢出；移动端使用顶部菜单，审批卡改为单列，详情面板不超过 94vw。
- 状态在视图切换中保留，刷新或 `Reiniciar demo` 恢复初始演示状态。
- 配套一份中文功能说明书，包含产品定位、页面说明、演示剧本、数据与安全边界。
